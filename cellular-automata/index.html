02 · DEFINITIONWhat is a cellular automaton?

01Grid

A regular grid of cells, in any number of dimensions.

02States

Each cell is in one of a few states, e.g. on / off (alive / dead).

03Neighborhood

Each cell has a set of nearby cells it can “see.”

04Rule

A fixed rule turns generation t into t + 1.

One automaton · many automata · abbreviated CA

04 · THE CLASSICConway’s Game of Life

Devised by British mathematician John Horton Conway in 1970.

  • 2D grid of square cells
  • Two states: alive or dead
  • 8 neighbors per cell
  • Zero players: set it up and watch
