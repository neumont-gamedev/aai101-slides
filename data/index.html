Data

The core ingredient that powers AI. Models learn patterns from numbers, text, images and sound, so the quality and variety of the data shape what they can do.

Data is the
new oil.

Crude oil is worth little until it’s refined. Raw data is the same: it has to be collected, cleaned and shaped before it can power anything.

phrase popularized by mathematician Clive Humby, 2006

noun

      
Machine learning trained on labeled data: every training example pairs the input with the correct output. The model learns to map inputs to outputs, then predicts outputs for new, unseen data.

FINDING THE CENTERMean, median, mode

        

      

      

        
Mean–Add them up, divide by how many. Outliers pull it around.

        
Median–The middle value once sorted (average the two middles if even). Resists outliers.

        
Mode–The most frequent value. Works for categories too. Can have two (bimodal).

      

      
click the line to add a value · click a dot to remove it · “average” usually means the mean, but always ask which one

TRAINING VS. TESTINGSplit your data

        
Train the model on most of the data, then test it on rows it has never seen. Otherwise you only learn how well it memorized.

        

          
test_size

          
          
80 training rows · 20 testing rows

        

        
common splits: 80/20 or 70/30

      

      

    

  


  
  

    
THREE SETSTraining, validation, testing

    
TRAINING 70%
VALIDATION 15%
TESTING 15%

    

      
Training
The examples the model learns from. It sees these over and over.
like the homework problems

      
Validation
Used during training to tune the model’s settings (hyperparameters, e.g. learning rate) and pick the best version.
like the practice quiz

      
Testing
A separate set the model has never seen, used once at the end to measure final accuracy and how well it generalizes.
like the final exam

    

  


  
  

    

      
IN CODEWhy random_state=42?


X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

      
The split is random. Fixing the seed makes it the same random every run, so results can be reproduced. 42 has no mathematical meaning: it’s a nod to The Hitchhiker’s Guide to the Galaxy, the “Answer to the Ultimate Question of Life, the Universe, and Everything.”

CAREERSFields and the people in them

    

      
FIELD
Data science
Uses statistics, programming and domain knowledge to extract insights from data and build predictive models.
KEY ACTIVITIESCollecting and analyzing data, building models, communicating results.

      
PERSON
Data scientist
Applies data science to analyze data, build predictive models and help organizations make data-driven decisions.
KEY SKILLSStatistics, machine learning, programming, visualization, communication.

      
FIELD
Data analytics
Examining data to find patterns, answer questions and gain insights that inform decisions.
KEY ACTIVITIESCleaning and exploring data, finding trends, building visualizations and reports.

      
PERSON
Data analyst
Collects, cleans, analyzes and visualizes data to help organizations understand trends.
KEY SKILLSData cleaning, SQL, Excel, data visualization, reporting.

    

    
Data science is one of the fastest-growing technology fields, with roles in nearly every industry.
