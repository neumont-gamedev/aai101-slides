FROM REGRESSION TO CLASSIFICATIONWhy not just a line?

Same study-hours data, but now the label is pass (1) or fail (0). We want the probability of passing.

1Fit a straight line

ŷ = wx + b keeps going: above 1 and below 0. A probability of 1.3 means nothing.

2Squash it with the sigmoid

σ(z) = 1 / (1 + e−z) bends any number into 0 – 1.

Logistic regression = linear regression + sigmoid. Same w and b, then squash the output into a probability.

K-NN STEP BY STEPHow the vote works

1Choose k

The number of neighbors that get a vote. Usually odd, and tuned by experiment. Here, k = 5.

2Measure distances

From the new point to every training point. Usually straight-line (Euclidean) distance.

3Find the k nearest

Keep the 5 closest points. These are the neighbors.

4Vote

The most common class among the neighbors wins.

70 / 15 / 15 is common too. The exact numbers matter less than keeping the sets separate.

THREE SETSTraining, validation, testing

Training · 80%

The examples the model learns from. It sees them over and over, adjusting its parameters to reduce error.

like the homework problems

Validation · 10%

Used during development to tune settings (hyperparameters, e.g. learning rate) and catch overfitting early.

like the practice quiz

Testing · 10%

Used once, at the end. The model has never seen it, during training or validation, so it gives an honest score.

like the final exam
Validation helps improve the model. Testing only measures it. If you tune on the test set, it stops being an honest exam.
Terminology
validation
/ˌvaləˈdāSHən/noun
Checking a model on a separate set of data it did not train on, to see how well it generalizes and to guide decisions like tuning settings or stopping before it overfits.
Terminology
test
/test/noun
The final evaluation of a trained model on data it never saw during training or validation: an unbiased measure of how it will perform in the real world.
Terminology
error
/ˈerər/noun
The difference between the actual value and the model’s predicted value: how far off one prediction is.

The real goal

Generalization

A model’s ability to make accurate predictions on new, unseen data, using patterns it learned from its training data.

The goal is not a perfect score on the training data. A student who memorizes the homework answers but can’t apply the concepts aces the homework and fails the exam. We want the one who can apply what they learned to new problems.

TWO KINDS OF MISTAKESBias and variance

Bias · consistently off

Error from a model that’s too simple for the data. It misses the target the same way every time. High bias → underfitting.

Variance · all over the place

Error from a model that’s too sensitive to its training data. Retrain on slightly different data and the answers jump around. High variance → overfitting.

Each dart = the model trained on a different sample of data. The bullseye = the true answer. The goal: low bias and low variance.

Terminology · in a model
bi·as
/ˈbīəs/noun
When a model makes overly simple assumptions about the data and misses the real pattern. Predictions are consistently off on both training and test sets, usually from underfitting.

Not the same as the unfair bias from skewed data in the Data deck, though both make predictions wrong in a consistent direction.

Terminology · in a model
variance
/ˈverēəns/noun
When a model is overly sensitive to small changes in its training data and learns the noise along with the pattern. High training accuracy, poor test accuracy, usually from overfitting.
