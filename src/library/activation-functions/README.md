# Activation functions slide (saved for a later deck)

Interactive graph that morphs between Step, Sigmoid, Tanh, ReLU and Linear, with a dot tracing
input → output. Taken out of AI History Part 1 (it fits better once students reach neural networks).

To use it in a deck:
1. paste `slide.html` into the deck's shell where the slide should go
2. paste `slide.js` into the deck's app.js, next to the other slide modules
3. it relies on the shared helpers every deck already has: `$`, `A`, `ctxOf`, `ease`, colors (`Y`, `BLUE`, `INK`, `MUTE`)
   and the `.stage-box`, `.seg`, `.btn`, `.stack`, `.two`, `.rise` styles
